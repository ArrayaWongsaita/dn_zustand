# ส่งต่อให้ผู้สอนก่อนประกาศรุ่น

สถานะ: มีหลักฐานตรวจอัตโนมัติใน [รายงานล่าสุด](readiness/latest.md) และ [JSON ตาม commit](readiness/latest.json) การทบทวนเนื้อหาโดยผู้สอนยังไม่ดำเนินการในงานอัตโนมัตินี้ ยังไม่ประกาศว่าพร้อมสอนหรือได้รับการอนุมัติ เผยแพร่ครบ 18 branches แล้ว และยืนยัน commit/เอกสารผ่าน GitHub API ตาม [หลักฐาน remote](readiness/remote.json) CI จริงยังไม่เริ่ม: push และ draft PR ยังไม่สร้าง run และ manual dispatch ได้ HTTP 404 ตาม [สถานะ CI](readiness/ci.json) เตรียม workflow ชั่วคราวแล้ว แต่ยังรออนุญาตก่อนเพิ่มไฟล์ใน main ไม่อ้างว่า CI ผ่าน

## รายการที่ผู้สอนต้องทบทวน

- [ ] อ่านเนื้อหาและตัวอย่างทั้ง 8 บท ภาษาและคำศัพท์จำนวนรายการ/จำนวนชิ้นรวม/ยอดรวมตรงกัน เหมาะกับผู้รู้ React เบื้องต้น
- [ ] ทดลอง lab จาก commit ในรายงาน จุดตั้งต้นเปิดแอปได้ บทก่อนหน้าสมบูรณ์ แต่ไม่มีคำตอบของโจทย์ปัจจุบันหรือบทอนาคตหลุดเข้า lab
- [ ] ตรวจคำใบ้สามระดับ เปิดใช้ได้เอง นาที 5/10/15 และไม่แจกคำตอบเต็มก่อนเฉลย
- [ ] อ่าน checklist และคำถามเหตุผลของ selectors/derived/local state ทดลองคำตอบโดยไม่พึ่งแค่หน้าจอ
- [ ] อ่านเฉลยและเหตุผลของทุกบท ตรวจลิงก์กลับ lab และเปรียบเทียบ ไม่ผ่อนเกณฑ์สำเร็จผู้เรียน
- [ ] ทดลองทุกลิงก์ GitHub หลังเผยแพร่ branches (ผล local ยืนยัน object ใน Git ยังไม่ยืนยันการเข้าถึง remote)
- [ ] ตรวจ exact expected failures ของ lab กับสิ่งที่ให้เติม ความผิดพฤติกรรมบทก่อนหน้าต้องไม่ถูกยอมรับ
- [ ] ทดลองกิจกรรมทบทวน mutation แยกจากเฉลยบทปกติ หน้าจอผ่านแต่ข้อมูลเดิมถูกแก้ แล้วอธิบายเหตุผลการ copy object ได้
- [ ] ทบทวนตาราง 360 นาที การพัก และการช่วยผู้เรียนที่ติดโดยให้จดจุดกลับมาฝึก
- [ ] ทดลองเก็บงานที่ยังไม่เสร็จ ไปบทใหม่ กลับ branch เดิม และลองเฉลยแยก โดยงานเดิมไม่หาย
- [ ] ตรวจผล CI จริงตาม commit และบันทึก URL ของ run/artifact ก่อนประกาศรุ่น
- [ ] ระบุผู้ทบทวน วันที่ และ commit ของรุ่นที่อนุมัติ พร้อมข้อจำกัดที่ยังยอมรับร่วมกัน

ผลทดสอบ Git workflow ใน clone แยก: สร้าง `my/01-basic-store`, commit งานที่ยังไม่เสร็จ, ไป `my/02-actions`, กลับ branch เดิม, สร้าง `try/01-basic-store-solution`, แล้วกลับมางานเดิมได้โดย notes ยังอยู่และ worktree สะอาด ไม่ต้อง merge/rebase/stash/push นี่เป็นหลักฐานการเก็บงาน ไม่ใช่การทบทวนคุณภาพการสอน

## ดูแลระหว่างรุ่น

อ่าน [คู่มือดูแล](MAINTENANCE.md) แยก commit เครื่องมือจากเนื้อหา กระจายเฉพาะ commit ที่เกี่ยวข้องและตรวจทุก branch ที่รับการแก้ ห้าม merge ทั้ง branch เพื่อส่ง patch เพราะอาจพาเฉลยข้ามบท ระหว่างรุ่นแก้เฉพาะปัญหาขวางการเรียน แจ้งบท ส่วนที่กระทบ และ commit ที่แก้

ให้ผู้เรียนแก้เฉพาะจุดเมื่อทำได้ หากต้องรับ lab ใหม่ ให้ commit งานเดิม สร้าง branch ส่วนตัวใหม่จาก lab ที่แก้ เปิดงานเก่าเทียบแล้วคัดลอกเฉพาะคำตอบ ผู้เรียนไม่ต้อง merge/rebase ปรับเนื้อหาและ dependencies ตามปกติระหว่างรุ่น

ข้อค้นพบเครื่องมือ: npm audit ของ starter พบ 7 high vulnerabilities ใน dependency chain ของ shadcn ที่สืบทอดมา (braces, GHSA-vfj7-8cjw-p6xm) ยังไม่ได้ปรับ dependencies แบบ force งานนี้ตรวจพฤติกรรมคอร์ส ไม่ถือว่าผล tests ผ่านเป็นการตรวจความปลอดภัยของ dependencies ผู้ดูแลควรแยกงานปรับเครื่องมือ ทบทวนผลกระทบและตรวจทุก branch ที่รับการแก้
